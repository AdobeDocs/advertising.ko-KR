# 일부 일괄 시트 부록 파일 도입에 사용된 단락

각 일괄 시트에는 수행할 [특정 작업](/help/search-social-commerce/campaign-management/bulksheets/bulksheet-data-formats/bulksheet-operations.md)에 필요한 헤더 필드와 해당 데이터 필드가 포함되어야 합니다(예: 광고 만들기). 필드가 필요하지 않으면 헤더 및 데이터 행에서 필드를 생략할 수 있습니다. Bulksheet 파일을 업로드하면 모든 사용자 정의 열이 삭제됩니다.

다음은 사용 가능한 헤더 필드 및 해당 데이터 필드에 대한 설명과, 데이터를 추가, 편집 또는 삭제하는 데 필요한 추가 정보입니다.
