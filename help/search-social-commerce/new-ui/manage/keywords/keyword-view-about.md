# (새 UI) [!UICONTROL Keywords] 보기에 대한 정보

*Beta 기능*

[!UICONTROL Manage] > [!UICONTROL Keywords] 보기에는 두 개의 탭이 있습니다.

* [!UICONTROL Keywords] 탭에는 선택한 광고주 계정에 대해 필터링된 보기의 모든 키워드가 나열됩니다.

* [!UICONTROL Negatives] 탭에는 선택한 광고주 계정에 대해 필터링된 보기의 모든 부정적인 키워드가 나열됩니다.

## 사용 가능한 작업

* [키워드에 제한 할당 및 키워드에서 제한 할당 해제](/help/search-social-commerce/new-ui/manage/keywords/keyword-constraint-assignments-manage.md)

* 키워드에 [레이블 분류 할당](/help/search-social-commerce/new-ui/set-up/label-classifications-manage.md)
