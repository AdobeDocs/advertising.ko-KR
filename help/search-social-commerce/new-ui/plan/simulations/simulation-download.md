# 시뮬레이션 다운로드

<!-- No subfeature tag for simulations or portfolios -->

*Beta 기능*

[!UICONTROL Simulations] 보기에서 한 번에 최대 10개의 주간 또는 사용자 지정 시뮬레이션을 다운로드할 수 있습니다. 단일 시뮬레이션은 [!DNL Microsoft Excel] 통합 문서(XLSX 파일)로 다운로드됩니다. 여러 시뮬레이션의 경우, 각 시뮬레이션에 대해 하나의 통합 문서나 별도의 통합 문서가 포함된 ZIP 파일을 다운로드할 수 있습니다.

시뮬레이션을 다운로드하려면 [!UICONTROL View Simulation] 권한으로 [!UICONTROL Simulations] 보기에 액세스해야 합니다.

>[!NOTE]
>
>* [시뮬레이션 결과를 화면에서 ](simulation-view.md)볼 수도 있습니다.
>* 많은 추가 지표와 대부분의 시뮬레이션 설정에 대한 열을 포함하도록 [[!UICONTROL Simulations] 보기를 사용자 지정](/help/search-social-commerce/common-tasks/data-views/custom-default-views-manage.md)할 수 있습니다. 포함할 수 있는 열에 대한 자세한 내용은 &quot;[시뮬레이션 정보](simulation-about.md#simulations-actions)&quot;의 &quot;사용 가능한 작업&quot; 섹션을 참조하십시오.
>* [!UICONTROL Portfolios] 보기에서 최대 100개의 포트폴리오에 대한 주간 시뮬레이션을 [다운로드](/help/search-social-commerce/new-ui/manage/portfolios/portfolio-create-simulation.md#download-simulations)할 수도 있습니다.

1. 메인 메뉴에서 **[!UICONTROL Plan]>[!UICONTROL Simulations]**&#x200B;을(를) 클릭합니다.

1. 다운로드할 최대 10개의 시뮬레이션 옆에 있는 확인란을 선택합니다.

   상태가 [!UICONTROL Successful]인 시뮬레이션만 선택하십시오. 선택한 시뮬레이션의 상태가 [!UICONTROL Failed], [!UICONTROL Queued] 또는 [!UICONTROL In Progress]인 경우 다운로드가 시작되지 않습니다. 다운로드하기 전에 이러한 선택 내용을 지웁니다.

1. 데이터 테이블 위의 도구 모음에서 **[!UICONTROL Download Simulation]**&#x200B;을(를) 클릭합니다.

1. (여러 시뮬레이션을 선택한 경우) 다운로드 옵션을 선택합니다.

   * **[!UICONTROL Download as Single File]**: 선택한 모든 시뮬레이션이 포함된 통합 문서 하나를 다운로드합니다.

   * **[!UICONTROL Download as Multiple Files]**: 선택한 각 시뮬레이션에 대해 별도의 통합 문서가 포함된 ZIP 파일을 다운로드합니다.

브라우저의 일반적인 절차에 따라 파일이 다운로드됩니다. ZIP 파일을 다운로드하는 경우 압축을 해제하여 통합 문서를 봅니다.
