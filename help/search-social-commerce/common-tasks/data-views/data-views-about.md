# 캠페인 관리 보기에서 데이터 사용자 정의 기본 정보

대부분의 캠페인 데이터 보기에서 데이터 테이블 내에 표시되는 데이터를 사용자 지정할 수 있습니다. 다음과 같은 방법으로 데이터를 사용자 지정할 수 있습니다.

* 특정 열 순서, 필터, 날짜 범위, 속성 규칙 등을 포함하도록 특정 엔터티 보기(예: [!UICONTROL Campaigns])에 대한 [전체 기본 보기의 설정을 편집하고](/help/search-social-commerce/common-tasks/data-views/custom-default-views-manage.md##view-edit) 설정을 일시적으로 적용하거나 저장하십시오. [추가 사용자 지정 보기를 만들고](/help/search-social-commerce/common-tasks/data-views/custom-default-views-manage.md#create-custom-view), [기존 보기를 복제하고](/help/search-social-commerce/common-tasks/data-views/custom-default-views-manage.md#view-clone), [원하는 보기를 적용하고](/help/search-social-commerce/common-tasks/data-views/custom-default-views-manage.md#apply-a-default-or-custom-view)할 수도 있습니다.

* 도구 모음에서 [!UICONTROL Custom Columns] 컨트롤을 사용하여 [열과 정렬 순서를 변경합니다](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/column-set-edit-sort-icon.md). 새 UI에서 도구 모음이 너무 좁아서 컨트롤을 표시할 수 없는 경우 **[!UICONTROL Actions]>[!UICONTROL Custom Columns]**&#x200B;을(를) 클릭합니다. 보기의 열 머리글에서 [열만 변경](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/column-set-edit-column-heading.md)할 수도 있습니다.

* (기존 사용자 인터페이스만 해당) [왼쪽 탐색 패널에서](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/filter-using-left-panel.md)다음 작업을 수행할 수 있습니다.

  * 광고 네트워크별로 엔티티를 찾아보거나 검색하고, 엔티티 상태와 계정, 캠페인, 광고 그룹 또는 광고 세트의 상태별로 필터링합니다. 패널에서 엔티티 또는 엔티티 그룹을 클릭하여 하위 엔티티 보기를 로드합니다(예: 캠페인 이름을 클릭하여 해당 하위 광고 그룹을 봅니다).

  * 포트폴리오 또는 포트폴리오 그룹별로 캠페인을 검색하거나 검색하고, 엔티티의 상태와 포트폴리오 그룹, 포트폴리오 및 캠페인의 상태별로 필터링합니다. 현재 엔티티 보기 내에서 포트폴리오 그룹, 포트폴리오 또는 캠페인에 대한 데이터를 로드하려면 패널에서 포트폴리오 그룹, 포트폴리오 또는 캠페인을 클릭합니다.

  * 기본 보기에 액세스하고 편집하고 재설정할 수 있으며 사용자 정의 보기에 액세스하고 편집하고 삭제할 수 있습니다. 보기 이름을 클릭하면 적절한 보기가 로드됩니다.

* 사용 가능한 데이터 열에 필터를 적용하여 현재 탭에 표시되는 데이터를 변경합니다. 도구 모음의 단추에서 [열 머리글](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/column-filter-apply-from-column-heading.md) 또는 [필터를 만들 수 있습니다](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/column-filter-apply-from-toolbar.md). 캠페인 관리 보기의 경우 하위 엔티티를 열 때 필터가 해당하는 대로 유지됩니다. 예를 들어 \> 100번의 클릭으로 캠페인을 보고 해당 캠페인 내에서 광고 그룹을 여는 경우 \> 100번의 클릭으로 광고 그룹만 표시됩니다.

* 특정 날짜 범위를 저장하지 않은 모든 기본 및 사용자 지정 보기에 사용되는 [날짜 범위를 변경합니다](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/date-filter.md).

* 특정 열의 값에 따라 [데이터를 다시 정렬](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/column-sort.md)합니다.

* 페이지 하단에 25행, 50행, 100행, (기존 사용자 인터페이스만) 200행 또는 (기존 사용자 인터페이스만) [!UICONTROL Continuous Scroll]을(를) 표시할지 여부를 제어합니다.

## (새 UI) 데이터 테이블 컨트롤 {#data-table-tools-new-ui}

데이터 테이블 위의 도구 모음을 사용하여 데이터를 관리하고 표시 방법을 변경합니다. 사용 가능한 도구는 보기 및 권한에 따라 다릅니다.

도구 모음이 너무 좁아서 도구를 표시할 수 없는 경우에는 **[!UICONTROL Actions]** 메뉴에서 도구 모음을 찾으십시오.

사용 가능한 경우 다음 작업을 수행할 수 있습니다.

* 전환 데이터가 보고되는 방식을 제어하려면 [!UICONTROL Conversion based on]에서 *[!UICONTROL Click Date]* 또는 *[!UICONTROL Transaction Date]*&#x200B;을(를) 선택하십시오.

* 두 기간에 대한 성과를 비교하고 차이점을 표시하는 방법을 선택합니다. &quot;[날짜 범위별로 데이터 필터링](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/date-filter.md#compare-periods-new-ui)&quot;을(를) 참조하십시오.

* 도구 모음 또는 **[!UICONTROL Actions]** 메뉴에서 **[!UICONTROL Compressed Mode]**&#x200B;을(를) 사용하여 간결한 테이블 간격을 설정하거나 해제합니다.

  압축 모드가 켜져 있으면 도구 모음 버튼이 선택됩니다. [!UICONTROL Actions]에서 스위치는 현재 상태를 나타냅니다.

* 도구 모음 또는 **[!UICONTROL Actions]** 메뉴에서 **[!UICONTROL Charts]**&#x200B;을(를) 사용하여 차트를 표시하거나 숨깁니다.

  차트가 표시되면 도구 모음 버튼이 선택됩니다. [!UICONTROL Actions]에서 전환은 차트가 표시되는지 여부를 나타냅니다. 차트를 숨기려면 컨트롤을 다시 클릭합니다.

## (새 UI) 열 너비 및 테이블 값 {#column-widths-values-new-ui}

Campaign 데이터 테이블에서:

* 열 제목 사이의 경계를 끌어 열 크기를 조정합니다. 먼저 잠금을 해제하지 않고도 적격한 [잠긴 열](/help/search-social-commerce/common-tasks/data-views/ad-hoc-settings/column-set-edit-lock-unlock.md)의 크기를 조정할 수도 있습니다. 최소 너비는 값을 읽을 수 있도록 유지하는 데 도움이 됩니다. 일부 아이콘 및 작업 열의 너비가 고정되어 있어 크기를 조정할 수 없습니다.

* 전체 이름을 보려면 잘린 엔티티 이름 위에 커서를 놓습니다.

* 이름이 링크인 엔터티의 세부 정보를 열려면 이름이 강조 표시될 때까지 **Tab**&#x200B;을 누른 다음 **Enter**&#x200B;을 누릅니다.

* en 대시(-)는 누락, NULL 또는 적용할 수 없는 값을 나타냅니다. 0과 false 값은 계속 표시됩니다.
