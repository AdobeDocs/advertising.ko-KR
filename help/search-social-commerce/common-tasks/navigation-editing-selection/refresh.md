# 관리 보기의 데이터 새로 고침

* (새 UI) 적용 가능한 관리 보기에서 페이지 제목 옆에 있는 ![새로 고침](/help/search-social-commerce/assets/refresh-new.png "새로 고침") 컨트롤을 클릭합니다.

* (기존 UI) 데이터 테이블 하단에서 ![새로 고침](/help/search-social-commerce/assets/refresh.png)을 클릭합니다.
